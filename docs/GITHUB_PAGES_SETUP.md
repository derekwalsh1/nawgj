# 🌐 GitHub Pages Setup Instructions

Your HTML web pages are ready! Follow these simple steps to make them live:

---

## Step 1: Enable GitHub Pages

1. **Go to your GitHub repository:**
   ```
   https://github.com/derekwalsh1/nawgj
   ```

2. **Click on "Settings"** (at the top of the repository page)

3. **Click on "Pages"** (in the left sidebar under "Code and automation")

4. **Under "Build and deployment":**
   - **Source:** Select "Deploy from a branch"
   - **Branch:** Select "master" (or "main")
   - **Folder:** Select "/docs"
   - Click **"Save"**

5. **Wait 1-2 minutes** for GitHub to build your site

6. **Your pages will be live at:**
   ```
   https://derekwalsh1.github.io/nawgj/
   https://derekwalsh1.github.io/nawgj/privacy.html
   ```

## Troubleshooting

### Pages not showing up?
- Wait 2-3 minutes after enabling GitHub Pages
- Make sure you selected "/docs" as the folder
- Check that branch is "master" or "main"
- Try hard refresh (Cmd+Shift+R)

### 404 Error?
- Verify GitHub Pages is enabled
- Check the branch and folder settings
- Make sure files are in the docs folder
- Wait a few more minutes

### Need to update content?
- Edit the HTML files in `/docs/`
- Commit and push changes
- Pages update automatically (takes 1-2 minutes)
